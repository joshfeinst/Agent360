# Night log — the method round

No player session started this one. The previous round's own diff got a
high-effort adversarial read, and the reviewer's charge was not that the fixes
were wrong but that some of them were **untested, and some of the tests were
untestable** — asserting a tautology, or a DOM fact, or a pure helper standing
in for the wiring that had actually shipped broken. So this round is about the
questions the suite asks. A test that names the bug it remembers only ever
catches that bug again; a test that names the *property* catches the next one
too. Three of the four gameplay defects below were found by rewriting a
remembered question as a generic one, and then reading what fell out.

# Night log — the promises round

The method round ended with a rule of thumb: a test that names the bug it
remembers only catches that bug again. This round applied it to the things the
game *tells* the player, and to the two failure modes that produce no error at
all — a character the map loader does not answer, and a sound name the sound
table does not have. Both fail into silence, which is the one symptom nobody
reviews.
